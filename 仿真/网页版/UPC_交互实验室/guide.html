自由探索，也让结果可解释。

弧线把两帧观测、受力比较与虚拟检验放到同一工作台。网页和离线包使用相同的 JavaScript 科学内核，不依赖云端计算或外部字体。

先完成第一次操作

  1. 在“观测预测”中拖动任一坐标。数字与观测标记立即更新，后台重新拟合轨迹。
  2. 停下拖动后，程序自动运行候选比较与独立扰动评估。可取消自动计算，改用“运行完整分析”。
  3. 在“查看组合”选择候选，转动三维视图或切换俯视、侧视、球门视角。
  4. 切到“虚拟射门”，调整初速、旋转作用与风场，生成有完整参考答案的模拟射门。
  5. 保存实验、导出配置或完整报告。保存记录可重新打开；精确输入不会被滑条步长截断。

预览用于即时理解变化。完整统计结果只在任务完成后更新。编辑过程中导出的报告和预测函数始终对应上一份完整结果，并会提示。

每个参数是什么角色

参数观测预测虚拟射门
两帧 x/y/z实际输入，可自由调节由参考轨迹生成；也可手动修改为明确的观测情景
质量、半径、空气密度、重力、起始高度声明的已知条件界面同时设定生成器和预测已知条件
初速度、Cᴅ、有效 b由各候选反演，不以参考真值作为答案控制参考轨迹，真值不提供给反演
风速可选组合的给定风情景控制参考风；是否将该情景提供给候选由组合开关决定
σ人为声明的坐标误差标准差生成观测噪声，并作为预测的误差假设

物理半径增大后，初始球心必须不低于半径；不合法输入会提示。有效 b 单位 s⁻¹，不是实测转速。界面上的操作范围是探索范围，不是文献置信区间。M0/M1解析基准、M2/M3有界反演的工作域分别记录于导出数据。

综合方法

两帧位置 → 枚举受力组合 → 共享观测扰动 → 分别重拟合和首飞预测
筛选：残差相容性 + 到达/失败比例 + 样本量 → 比较 S = √tr Cov(y,z)
冻结所选/并列候选 → 独立随机流评估 → 条件密度与边际范围
虚拟验证：只给预测方法两帧 → 再检查模拟参考落点是否被覆盖

默认门限为名义 RMSE/σ≤2、到达比例≥90%、输入/拟合/数值/工作域失败≤5%、至少20个有效样本。它们是公开可复现的工程规则，不能作为统计显著性检验。独立评估的两个95%边际范围不是95%联合区域。集中度最小不能证明真实物理模型正确。

球心首次向前穿过 x=11 m 为到达事件，先触地则结束首飞。没有碰撞、门将或地面反弹模型；球心入框与比赛裁判的整球越线不同。门外样本和所有失败类别保留，数值失败不算真实射失。

虚拟验证与批量实验

虚拟验证保留生成器完整轨迹，只把带噪声的两帧交给反演。可以固定工况重复噪声，或按取值列表扫描风速、初速、阻力与有效旋转。所有候选使用同批观测，输出误差、到达/失败分母以及区域覆盖和面积。生成器不是现实真值，模型相近时的良好结果也不能证明模型遗漏情况下仍可靠。

经验 Mahalanobis 椭圆根据当前点云构造，其“95%”指样本分布口径，是否在不同工况覆盖参考真值必须测试。当前批量功能不会自动把未校准区域包装成可靠95%预测区间。实验探索后，应冻结方法与条件，再换独立工况/种子检验。队伍自行选择论文实验与结论。

导出与离线使用

  • 配置 JSON：当前编辑状态，用于恢复实验。
  • 预测函数 JS：完成时配置下的算法映射 F(p₀.₀₅,p₀.₁₀)，传入新坐标会重新计算。
  • 研究数据 JSON：样本、拟合、候选判定、独立评估和配置。
  • 完整报告 HTML：独立可打开、可打印，包含完成快照的图表与方法。
  • 轨迹 PNG：当前视图图像，适合讨论或检查；正式结论用完整报告绑定输入。
// Node.js，无需第三方运行依赖
const {F} = require('./综合预测映射.js');
const r = F([1.50,0.45,0.44],[2.96,0.86,0.74]);
console.log(r.mappedPrediction, r.uncertainty);

离线使用：完整解压后用 Edge 或 Chrome 打开 index.html。该应用使用 Canvas、Blob Worker 和本地文件下载。浏览器禁止本地 Worker 时会明确提示，应改用本地 HTTP 服务或网页端。

比赛用球规格

依据 IFAB 2026/27 第2章，足球周长为68–70 cm、开赛时质量410–450 g，海平面规定压力0.6–1.1 atm；FIFA及洲际足联正式赛事还要求相应质量认证标记。半径由周长换算约0.1082–0.1114 m。默认0.43 kg、0.11 m位于该范围；滑条允许更广的敏感性探索。模型没有将球内压力等同于环境气压，也没有声称某品牌球已获认证。详见 来源和许可证记录。

来源与实现范围

  • UPC 2026 官方题面：两帧时刻、位置及球门几何。未提供测量标准差、风或真实自旋。

  • SciPy KDE 文档：高斯核/带宽背景，内核独立实现并有跨实现验证。未捆绑SciPy。
  • Asai & Hong 2021：特定球型非旋转风洞研究，CC BY 4.0；作为实验背景，不能将本工具常数Cᴅ或有效b宣称为该论文的通用实验标定。
  • W3C 滑条交互规范、Material 滑条设计、web.dev 响应优化：用于键盘操作、精确输入和后台计算的设计参考。界面代码与图形为本项目原创。
