弧线 · 足球预测实验室

1. 先完整解压离线包，用 Edge 或 Chrome 打开 index.html。
2. 左侧六个滑条对应两帧 x/y/z。右侧输入框支持比滑条步长更细的精确值。
3. 拖动时立即更新观测点，并在后台更新轨迹。停止调整后自动开始完整统计；也可以取消自动计算，手动点击“完整分析”。
4. 右上角可旋转、缩放三维视图，切换俯视/侧视/球门面，或分页并排比较全部组合的热图。
5. “虚拟射门”可以调节参考初速度、阻力和有效旋转，再检查只得到两帧的预测方法与参考的差异。
6. 质量/重力、阻力、旋转、风、观测误差分别收在独立参数组。观测模式中需要反演的参数会明确标识。
7. 完成后可保存实验、导出配置、研究数据、可重算的映射函数或完整 HTML 报告。报告可由浏览器打印成 PDF。
8. 需要批量扫描时打开“批量验证”。先用少量重复试运行，再按论文实验设计增加预算。所有失败和未到达事件保留分母。

详细方法、参数角色、适用范围与来源见 guide.html 和 sources.json。
此版本提供交互与仿真实验工具；代码验证和少量演示不能替代论文所需的大规模独立测试或真实测量校准。

可复现命令（可选，需要本机 Node.js；离线网页本身无需安装）：
  node run-lab.cjs study 已导出的配置.json 研究结果.json
  node run-lab.cjs virtual 已导出的虚拟配置.json 虚拟结果.json
  node run-lab.cjs default-batch 批量配置.json
  node run-lab.cjs batch 批量配置.json 批量结果.json

浏览器历史由本机存储；跨设备迁移应导出配置。所有科学计算在本机浏览器执行，无外部 CDN 依赖。
