# 三维资源选择与许可

核验日期：2026-11-07。当前交付包括 MATLAB 科学基准修复验证、用户追加授权的离线浏览器研究工具及有限 M4 正向扩展。

## 采用决定

MATLAB 保留原有 plot3 与按题给尺寸绘制的球门；浏览器已使用原生 Canvas 和独立编写的三维投影，程序绘制球面、门框、地面、轨迹与坐标轴，不引入外部网格、纹理或渲染库。计算采用 SI、右手坐标、z 向上；可拖动旋转、Shift 拖动平移、滚轮缩放，并切换正视、俯视、侧视。球标记为便于定位可放大，物理位置和坐标比例不随标记尺寸改变。

M0—M3 球面只是静态示意，不以有效 b 计算或播放真实自旋。M4 的球面子午线和放大姿态球使用计算得到的 scalar-first 四元数旋转；这展示的是给定角速度与假设力矩模型的姿态，不是摄影测得的真实姿态。未复制 FIFA 标志、商业比赛球花纹或精细接缝。

模型、纹理、渲染库和气动系数是不同来源。换球皮不切换气动系数；视觉球面不是 CFD 网格；尺寸合规不表示产品获得 FIFA 认证。

## 本轮运行依赖

- MATLAB：本机实测 R2025b（25.2.0.2998904），Optimization Toolbox 和 Statistics and Machine Learning Toolbox 许可可用。商业软件不打包，接收者需自己的可用环境。
- NumPy 2.3.4 与 SciPy 1.16.3：仅用于独立数值复核，装于工作目录隔离环境；[NumPy许可](https://numpy.org/doc/stable/license.html)、[SciPy许可](https://github.com/scipy/scipy/blob/v1.16.3/LICENSE.txt)为 BSD 类许可并各有组件声明。包内只放固定依赖清单，不分发二进制依赖。MATLAB是主模型，Python是独立验证。
- 浏览器运行依赖为内置 Canvas、Web Worker、Blob 与本地经典 JavaScript 脚本；物理内核、三维投影与界面均在包内，无在线服务、账号或 CDN 依赖。M4 论文关系独立编码，来源许可限制见《气动力证据与接入决策》。
- 未引入 third-party 浏览器求解库、three.js、Plotly 或游戏物理引擎；上表候选的安装兼容性未因本页可运行而视为已验收。dLeom 网格未下载、不随包分发。

本地网页通过真实求解更新轨迹；外观与渲染帧率不决定积分步长。现有视觉不等于球面形变模型、真实接缝气动、风洞测量或 CFD，球型下拉框只选择已明示的系数关系。

## 队内演示导出

网页可取消地生成一张固定相机的 12 帧 PNG 联系表，每格标注模型与积分样本时间。配置、求解器/界面版本、相机、显示项和帧时刻记录在 PNG 的 `UPC-Metadata` iTXt 字段，并可另存 JSON。它是静态联系表，不是视频或逐帧 ZIP。轨迹与姿态取同一最近积分样本；视图时间插值不会伪装成额外物理求解。科学球门正视图另有无标题 PNG 导出。
