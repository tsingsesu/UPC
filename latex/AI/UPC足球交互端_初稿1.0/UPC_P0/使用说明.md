# UPC 足球研究台 · 离线版 1.0

这是供你们随实验进度和论文撰写选择模型、配置实验的交互研究入口，包含 M0—M3 观测反演、M4 真实角速度正向研究，以及修复后的 MATLAB 源码和验证证据。已有批量实验是程序验收和示例，不是替团队选定的论文实验方案或结论。无需 MATLAB、账号或网络即可使用网页。它回答的是声明假设下的首飞预测；尚未完成实球实验确认。

## 打开与开始

1. 将整个 ZIP 解压到一个文件夹，保留目录结构。不要在压缩包预览窗口中运行。
2. 用 Edge 或 Chrome 打开根目录 `index.html`，或直接打开 `src/web/index.html`。无需启动服务器。
3. 页面会自动计算官方输入。点击“恢复官方算例”可恢复原始坐标，再点击“计算轨迹”。
4. 在“观测反演”中修改六个观测坐标中的任意一个，再计算。黄色覆盖层表示输入已改变，图中仍为上次完整结果。
5. 选择“正向”可直接改初速度、阻力、有效旋转参数与风。M4 仅支持正向；输入真实角速度、球型与气动关系后重新计算。

网页固定两帧时刻为 0.05 s、0.10 s；题给初始球心为 (0,0,0.11) m。源码接口可接收其他递增时刻，网页导入会拒绝其他时刻，避免隐藏地改变题目。半径与初始球心高度分别保存；增大半径导致球心低于接触高度时会报错。

## 如何比较、观察和导出

- M0 是重力基线；M1 是常加速度代数延拓；M2 增加平方阻力；M3 增加有效 `b×w` 力；M4 求解真实角速度与四元数。M3 的 b 单位为 s⁻¹，不能当作 rpm。
- 模型比较支持“同一观测，各自重新拟合”和“固定初态，只切换方程”。它们回答不同问题，图注会记录选择。
- 拖动场景旋转，滚轮缩放，Shift＋拖动平移；切换球门、俯视或侧视，暂停或拖动时间轴。球面标记是几何示意；M4 才有动力学姿态。
- 时间曲线可查看位置、速度、加速度、各力；M4 另有角速度、姿态、力矩、气动系数、雷诺数与自旋比。
- 先设置噪声假设 σ，再选 bootstrap 或确定性情景扫描。bootstrap 需要 σ>0；情景扫描没有概率权重。样本数 10—600；可随时取消。边界命中会与其他事件计数重叠。
- 保存配置 JSON 可交给队友；关闭网页后重新打开并导入，再计算即可重现。`data/示例/` 有官方、修改观测和 M4 情景。
- 导出结果 JSON 保存完整运行及统计；轨迹 CSV 保存运动、力与 M4 转动量；样本 CSV 保存每次状态。PNG 是独立论文图，图注单独导出。配置变化但尚未重算时，结果导出仍对应上次完整运行。
- “12 帧联系表”将当前视角和模型导出为一张 4×3 PNG，含帧时刻，可用于队内演示；配置与版本嵌入 PNG，也可另存演示配置 JSON。生成可以取消。这是帧联系表，不是视频录制。

所有长度以 m、时间以 s、质量以 kg、力以 N、角速度以 rad/s 表示。坐标 x 朝向门平面，z 竖直向上，y 为有符号横向坐标。

## 官方算例的回归数值

在 M3、静风、m=0.43 kg、R=0.11 m、ρ=1.225 kg/m³ 等当前假设下：

| 量 | 计算值 |
|---|---:|
| 球心首次向前到达 x=11 m 的时间 | 0.4005034861 s |
| 横向位置 y | 2.5994405492 m |
| 高度 z | 1.9670046155 m |
| 初速度 (vx,vy,vz) | (30.41545909, 9.41672478, 6.90801418) m/s |
| 常阻力系数 Cd | 0.3706870077 |
| 有效 (by,bz)，固定 bx=0 | (−0.0603256440, −0.3571277815) s⁻¹ |

这些小数用于程序回归，不代表实测精度。M1 的 t≈0.4050083612 s、y≈2.4948244142 m、z≈1.9203670565 m；模型不同导致答案不同，不能凭残差更小就断言更真实。

“到达球门平面”“球心位于开口内”“具有球半径几何余量”分别报告。程序不求门柱碰撞、守门员或触地反弹，题目球心 x=11 m 的事件也不等于足球规则的整球过线判罚。

## 气动扩展的边界

M4 可选 Kiratidis/Leinweber 文献中的四种球型阻力拟合，以及限域 Teamgeist 升力关系。系数与球型、速度和自旋工况绑定；超出程序保护域会终止，不会悄悄外推。四球经验阻力以空气相对速度 U 为自变量；μ 用于 Re 诊断，改变温压湿度并未重新标定阻力危机，不能宣称任意天气下的通用 Cd(Re)。

线性升力斜率、惯量系数、自旋衰减时间、阵风和剪切风均保持可调假设。两帧位置不能同时识别真实自旋、风、球型和全部气动系数。默认值不是本题实测值；FIFA 尺寸认证也不提供这些系数。

600 次 MATLAB bootstrap 得到 435/600 满足当前无碰框余量。这是噪声与拟合算法假设下的稳定频率，不能称为真实进球概率。网页经验协方差椭圆未校准 95% 覆盖，不能称为后验区域。详细统计账目及低信息反演限制见知识文档。

## 验证与重运行

现成证据位于 `data/验证基准/`；MATLAB 全量运行位于 `data/验证运行/20261107T115635_full_tp99707eb1_fdd0_49be_af74_8b633a98c808/`。对应论文图位于 `img/验证运行/`。`data/基准快照/` 是与上游比较用的历史结果，勿与修复后结果混用；其中个人绝对图路径已脱敏，原文件哈希与变换记录在来源清单中。

仅使用网页不需要安装任何依赖。以下步骤只供复查源码与再生成证据。

从包根目录启动 MATLAB（本机实测 R2025b，使用 Optimization Toolbox；原团队版本 R2024a 未在本轮重新验收）：

```matlab
addpath('src');
report = Mai_p0_validate('full');
Mai_web_reference();
Mai_advanced_reference();
```

`full` 使用 600 次 bootstrap 和 150 个合成样本；`quick` 是较小预算。每次生成独立运行目录，避免覆盖原正式结果。纯计算使用 `Mai_penalty('quick',[],struct('writeOutputs',false,'makeFigures',false))`；该调用不写结果或图。

PowerShell 可从包根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\Mai复现结果.ps1 -Mode full
```

这只对本次进程选择执行策略，不修改系统策略。若需独立 Python DOP853 复核，先在独立虚拟环境中按 `src/requirements-validation.txt` 安装固定依赖，然后给脚本传 `-PythonExe` 指定该环境的解释器；或按 `Mai独立复核.py --help` 指定输入与输出文件。包不含 Python 环境、MATLAB 安装文件或许可证。

Node 数值回归不需 npm 库：

```powershell
node src/web/physics.test.cjs --write-report
node src/web/advanced.test.cjs
node src/web/environment.test.cjs
node src/web/robustness.test.cjs --write-report
```

浏览器端到端验收另需 Playwright 测试库和本机 Edge/Chrome，执行 `node src/web/browser.test.cjs`。可用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块，用 `TEST_BROWSER_CHANNELS=msedge` 只测 Edge。测试源码会将网页复制到含中文和空格的临时路径并离线运行；这不是网页的运行依赖。
