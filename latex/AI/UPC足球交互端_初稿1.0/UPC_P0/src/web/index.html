开始一次可复现的实验

  1. 点击“恢复官方算例”，再“计算轨迹”。
  2. 选择 M0—M3，可在反演模式改任一观测，或在正向模式改初态。
  3. 拖动三维画面、播放时间轴，查看门平面与拟合诊断。
  4. 设置明确的噪声假设，再运行 bootstrap 或确定性情景。
  5. 保存配置 JSON，队友在同版本页面导入可重新计算。导出结果、CSV 和 PNG 用于复查。

不能从六个观测坐标同时辨识所有空气、自旋与环境参数。固定量、估计量与实验假设都应保留在论文中。b 是有效 Magnus 系数，不能换算成已知的 rpm。
