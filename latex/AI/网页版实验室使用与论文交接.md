## 题目交付与本软件的对应关系

官方 B 题要求从 t=0.05、0.10 s 两帧位置预测入射位置，发展并测试一般方法，估计预测不确定性，再应用于题给案例。它没有规定必须选择某一种不确定度标量或固定四个模型。

| 题目交付 | 当前软件提供 | 论文仍须决定或补充 |
|---|---|---|
| 一般映射方法 | `F(p05,p10; config)` 重新拟合、比较候选、传播误差 | 公开候选集合、约束、点估计定义及选择规则 |
| 题给案例预测 | 名义 y、z、t 和各候选条件结果 | 恢复原始题给数据，明确采用哪个方案；不要把改动坐标后的情景当题目原值 |
| 不确定性 | 条件点云、KDE、协方差、散布、边际范围、模拟经验椭圆 | 噪声依据、模型偏差、数值误差、联合区域覆盖校准 |
| 测试一般方法 | 虚拟参考、批量扫描、独立测试种子、失败账目 | 预先冻结方法、足够独立案例、有限样本误差条、必要的独立实测或文献验证 |

当前点预测来自原观测的名义拟合，并不是对 KDE 求最大值得到的众数。论文若称“most likely”，必须说明采用的统计定义；热图峰值、点云均值和名义轨迹交点不能默认互换。

## 最短使用路径

1. 用 Edge 或 Chrome 打开 `index.html`，点“恢复题面”，进入“观测预测”。
2. 先取消“停下拖动后自动计算”；在“观测误差与精度”选“快速探索 · 20 + 20”，保持其他条件不变，点“运行完整分析”。20+20 只是快速诊断预算。
3. 等到“完整分析已更新”，在“查看组合”切换显示对象，在“组合对照”看残差、到达分母和边界命中。
4. 先点“查看完整球门”确认位置，再“放大落点区域”看云形；“并排比较”用于同次运行的候选比较。
5. 导出“配置”“研究数据”“完整报告”。进入正式实验前，按统计精度需要确定预算并冻结方案。

“查看组合”只改变显示对象；左侧“候选组合”和风场开关才改变候选集合。“保存实验”只保存浏览器设置，最多12条；它不归档完整结果。“并排比较”不是历史实验比较。导出报告、研究数据和预测函数始终对应上一次完成快照；当前编辑未重算时不会混入旧结果。

## 参数角色与默认值

| 输入 | 角色 | 当前默认或单位 |
|---|---|---|
| 两帧位置 | 观测数据，六个坐标可调 | (1.50,0.45,0.44)、(2.96,0.86,0.74) m；时间固定0.05/0.10 s |
| 初始球心 | 声明为精确已知 | (0,0,0.11) m；界面只调初始高度 |
| m、R、rho、g | 声明已知；界面在虚拟模式同步修改参考与预测条件 | 0.43 kg、0.11 m、1.225 kg/m³、9.80665 m/s² |
| 初速、Cd、by/bz | 各候选反演自由参数；虚拟模式可设置生成器真值 | b 单位 s^-1，是有效组合参数，不是真实角速度/rpm |
| 风 | 给定均匀风情景，不从两帧联合反演 | 情景默认 [0,2,0] m/s；默认未勾选有风候选 |
| sigma | 坐标误差标准差假设 | 默认0.01 m；独立、各向同方差高斯噪声 |
| 两批样本 | 筛选和独立扰动评估 | 网页20+20、60+60、200+200；默认60+60 |
| seed | 确定性随机复现 | 默认20261107 |

虚拟模式下，风滑条控制参考风；“比较有风与无风的组合”只决定是否加入给定风候选。取消该勾选不等于把参考世界的风设为零。要做严格无风基准，请把三个风速数值设为0。

虚拟模式的同一个 sigma 同时用于生成观测噪声和预测端声明的误差；要专门研究噪声误设，需在 CLI 中分别设置 `observationSigma` 和 `study.sigma`。手动改虚拟两帧时保持参考轨迹不变，标记 `manualObservationOverride=true`，应解释为人工观测情景。

网页质量/半径等滑条范围用于敏感性探索，不是赛事合格范围；法规、气动力实验来源及许可证见 `sources.json`。未知参数和工程边界不能称为实验置信区间。

## 受力组合和事件定义

设 w=v-u，物理候选使用 dr/dt=v，dv/dt=(0,0,-g)-rho*pi*R²*Cd*|w|w/(2m)+b×w。重力是物理基底；关闭某受力时同时移除其反演参数。

- M0：重力；反演三分量初速。
- M1：常加速度代数对照；反演初速和三分量加速度。它不是在重力之上额外叠加的“场”。实际加速度在 `nominal.fit.constantAcceleration`。
- M2：重力+平方阻力；反演初速和常数 Cd。
- M3：重力+阻力+有效 Magnus；反演初速、Cd、by、bz，bx固定0。
- G_M：重力+Magnus、无阻力；与对应给定风情景可继续组合。
- 默认5个候选；启用非零风情景时最多8个（含M1）。无气动力时风不起作用，零风重复项会去重。

当前输出事件是球心首次穿过 x=11 m 的首飞事件；先触地终止。没有球门柱碰撞、反弹、守门员或完整足球越线判定。到达平面可能位于门框外。风是参数化情景，不是求解空间流体场。本版未启用旧初稿的M4真实角速度/经验气动力扩展。

## 统计流程和选择规则

对同一组原始观测 d，生成共同扰动 d_i=d+epsilon_i；每轮所有候选使用同一份扰动观测，分别重新拟合并预测。它是声明的观测误差下的传播近似，不是未经定义的贝叶斯后验。

默认资格门限在 `config.selection`：拟合成功，名义 RMSE/sigma≤2；总样本和到达样本均至少20；到达比例≥0.9；数值类失败比例≤0.05；sigma>0 且散布有限。这些门限可配置；快速20次中只要有1次未到达，就不满足默认的20个到达样本要求。数值类失败包含无效输入、拟合、积分和域外失败。触地、超时等另行分类。`boundaryHits` 单列，不自动排除或删除样本。

在合格候选中按 `summary.stabilityRMS_m=sqrt(trace(covarianceYZ))` 排序，协方差按到达点、n-1 分母计算。该量单位为m，表示围绕点云均值的散布，不是对真实落点的RMSE。

`stabilityInterval_m` 是对到达点云重抽样得到的 S 的有限样本变化区间，不是未来落点预测区间。与最小 S 候选区间重叠者保留在 `decision.candidateIds`；`uniqueSupported` 是当前启发式判断，不是正式模型真实性检验。

**当前排序未使用参考预测误差、覆盖率、椭圆面积或KDE峰值。** 批量验证指标用于研究者判断该选择规则是否可靠，软件尚未据此自动训练或修正选型规则。

## 热图的精确定义

只使用 `crossed_goal_plane` 样本的 (y,z) 构建每个候选的条件密度；门框外过平面点保留。核权重 `weights[i]=1/nArrival` 是到达样本的权重，不是候选模型权重。

\[
\hat f_m(y,z)=\mathbf 1_{z\ge R}\sum_i\frac{w_i\exp[-((y-y_i)^2+(z-z_i)^2)/(2h^2)]}{2\pi h^2\Phi((z_i-R)/h)}.
\]

每个核在 z≥R 截断并独立归一化；y不截断，门柱/横梁/显示窗口不重新归一化。Scott自动带宽为 `n^(-1/6)*sqrt((s_y²+s_z²)/2)`；实际 `h=max(手动 sigma_h 或 Scott 值, minBandwidth)`，默认下限0.001 m，手动指定也受下限约束。h只是平滑尺度，不是输入sigma，不参与S排名。不足2个到达样本或全部重合的点云不生成平滑二维密度；非重合共线点云仍可生成各向同性平滑KDE。零输入噪声不参与统计稳定性排名。

`conditionalDensity` 单位m^-2，积分为1；它可以大于1。某区域A的概率质量应积分密度，不能取某像素的红色数值当概率。`observedMassDensity=conditionalDensity*(nArrival/nTotal)` 保留尝试分母，数值失败并不因此成为真实物理事件概率。

例：100次算法尝试有90次到达，区域A的条件质量为0.60，则全尝试对应质量为0.54；这两个数都依赖噪声、候选、约束和算法，不能直接写成现实进球率。

绘图实际显示128×80网格的面积平均密度，颜色默认为 `log1p(10000*d/max)/log1p(10000)`。单图自适应色标；不能跨单图按红色深浅排序。主图优先 `assessment.models[].density`，无此候选则用筛选批 `schemes[].density`。并排图统一使用筛选批，统一坐标和色标。主图局部放大只是裁图，未把窗口内质量重新变为1。

这不是量子波函数，也不是场强图；可称“球门面条件预测密度”或“观测扰动传播的落点密度”。

## 独立评估与区域的区别

选择冻结后，只对 `decision.candidateIds` 重新传播观测误差，使用 `assessment.seed=(seed ^ 0xa5b35705)>>>0`，并标记 `selectionFrozen=true`。这是新伪随机流，仍围绕原两帧；没有新增真实射门，不能称为覆盖校准。

`marginalRanges.y/z/t` 分别为各分量2.5%-97.5%经验分位范围。两个边际95%范围拼成矩形，不自动具有联合95%覆盖。

模拟检验中，经验椭圆由点云均值、样本协方差和同批马氏距离平方的95%经验分位数q构建：`(p-mu)' inv(Sigma)(p-mu) <= q`，面积 `pi*q*sqrt(det(Sigma))`。至少6点；奇异时不造区域。该椭圆未裁地面或门框，与截断KDE不是同一个区域构造；它也不是KDE的95%最高密度区域。`calibrationStatus='not_calibrated'` 必须保留。

最终论文应区分观测传播、给定参数敏感性、模型偏差/模型间差异、数值误差、有限抽样误差。当前主云主要反映第一个来源；不是已经囊括全部来源的“总不确定度”。

## 模拟参考与批量指标

`generateReference` 使用同一个物理内核，以0.0005 s步长生成完整参考，`independentReferenceAlgorithm=false`。仅两帧含噪位置输入反演；不偷偷把参考初速/Cd/b作为估计答案。界面共享的m/R/rho/g/初始条件是显式声明的已知量。

`runExperiment` 返回 `{status,reference,study,evaluations,provenance,calibration}`。参考无法生成两帧或研究失败时 `study=null`，不要当成功案例丢弃。手动修改观测保留原参考轨迹，并记录生成观测和手动标记。

| 字段 | 分母与解释 |
|---|---|
| `positionRMSE_m` | 仅参考和预测双方都到达平面的案例 |
| `meanAbsoluteTimeError_s` | 同样仅双方到达；界面简表未列但JSON有 |
| `coverageAmongAvailableRegions` | 覆盖数/参考到达且有可用区域的案例数 |
| `coverageAmongAllTruthArrivals` | 覆盖数/全部参考到达案例，缺区域计未覆盖 |
| `coveredFractionAllAttemptedCases` | 覆盖数/全部尝试；不称空间覆盖率 |
| `meanRegionArea_m2` | 参考到达且区域可用的案例平均面积 |
| `regionSources` | pilot和assessment区域数量，防止混合解释 |
| `predictionStatusCounts` | 全部预测事件/失败分类，不能只保留成功者 |

例：80个参考到达，60个有区域，54个覆盖，则条件覆盖为54/60=90%，全参考到达覆盖为54/80=67.5%。应报告分子与两个分母。覆盖率自身也有抽样误差；当前页面未生成其误差条，应后处理。

批量 `phase='test'` 使用 `testSeed`；`heldOutCalibration=false`。操作者必须确保该种子未在任何探索批使用：界面中仅切换阶段，默认两阶段都可能实际使用20261108，生成相同观测。应先将“本批随机种子”改为未用过的新值（如20261109），再运行测试。程序对testSeed与当前seed的检查不等于追踪历史探索种子。冻结候选、约束、阈值和评价规则也由操作者负责。只换随机种子不等于用独立现实数据验证，不自动完成训练/校准/测试划分。

## 复现命令与最小调用

在实验室目录中运行，均为相对路径：

```text
node run-lab.cjs study 实验配置.json 观测结果.json
node run-lab.cjs virtual 虚拟配置.json 虚拟结果.json
node run-lab.cjs default-batch 批量配置.json
node run-lab.cjs batch 批量配置.json 批量结果.json
node validation/experiments.test.cjs
```

前两条读取网页导出的配置。批量输入必须从 `default-batch` 模板整理，不能把网页配置或批量输出直接作为批量输入。网页重新计算时会用预算下拉框覆盖两个样本数；任意预算、双轴扫描及噪声误设适合CLI。

```js
const {createPhysics}=require('./physics.js');
const {createDensity}=require('./density.js');
const {createStudy}=require('./study.js');
const {createMapping}=require('./mapping.js');
const {createExperiments}=require('./experiments.js');
const P=createPhysics(), D=createDensity(), S=createStudy(P,D);
const M=createMapping(P,D,S), E=createExperiments(P,D,S,M);
const c=E.defaultConfig();
c.reference.wind=[0,0,0];
c.study.sampleCount=60; c.study.assessmentCount=60;
c.repetitions=3; // 流程试运行；正式预算须另定
c.scan={axes:[{path:'Cd',values:[0.2,0.4]}]};
const result=E.runBatch(c);
// 导出研究用JSON时保留result.config、samples、summary、matrix和design。
```

网页导出的 `综合预测映射.js` 可 `require` 后调用 `F(p05,p10)`；新两帧将真正重算。`mappedPrediction.selected.prediction` 是名义预测；并列时 `provisional=true`。`uncertainty.selectedIndependentAssessment` 为选中候选的独立扰动结果。

`selectionSensitivity` 是额外的外层重选择敏感性接口，记录 `selectionCounts/ambiguousCount/noEligibleCount`；当前网页无完整的一键入口。其频率不是模型真实性概率。`betweenCandidateNominal` 也只是候选差异，`modelWeightsInferred=false`；没有自动生成加权混合密度。

## 建议实验与论文叙事

按以下顺序组织，数值情景均需在论文中声明为设计条件：

1. 原题两帧下的各模型名义预测与资格门限表，保持原始观测不变。
2. sigma=0.005/0.01/0.02 m等明确假设下的敏感性；六坐标逐个正负扰动属于确定性情景。
3. 模拟参考分别用重力、阻力、旋转机制生成，所有候选使用相同观测，形成生成机制×预测方法的比较表。
4. 有风参考与忽略风候选对照，检验“点云很窄但中心偏了”。先固定参考风，例如[0,3,0] m/s。
5. 初速、Cd、有效旋转或风的工况扫描；按工况分组统计，不能把扫描情景当自然总体分布。
6. 冻结规则后独立种子测试，同时报告误差、覆盖、面积和失败分母。若看到测试结果后调规则，再保留新测试批。

论文结构宜为：输入与问题定义→物理假设及可辨识性→候选方程→F映射和选择流程→数值验证→题给结果→误差传播与模拟覆盖→模型偏差和限制。正文应独立给出方程、输入、统计口径和静态图；网页作为复现工具，不能替代正文论证或官方要求的论文附件。

针对“最可能入射点”，至少明确采用名义预测、均值还是密度众数；如决定采用KDE众数，需要额外求峰与网格/带宽敏感性检验。针对“综合方案”，建议把可靠性/覆盖作为外部检验，再比较集中度；当前程序的最小S选择只是待检验的候选规则。

如果未来要把方案变化计入一个总分布，必须说明候选权重来自什么依据。不能给所有组合任意等权后称后验，也不能把选中频率当真实模型概率。没有可辩护权重时，可并列报告合格模型的分布与预测差异。
