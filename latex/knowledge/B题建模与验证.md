# B题：从短时观测到可核查的预测

## 选题与交付清单

选择B题：题给观测完整，可以形成“物理方程—反演—外推—不确定性—独立合成检验”的闭环。A题缺少初始速度方向、发动机参数和安全阈值，会增加假设主导结论的风险。这是工程可完成性判断，不是获奖概率保证。

| 题面要求 | 交付物 | 验收方法 |
|---|---|---|
| 一般预测方法 | 参数反演、事件定位、失败分类 | 合成轨迹重新生成观测并盲预测 |
| 最可能入门位置 | 指定模型和噪声假设下的最大似然参数预测 | 回代题给观测；Python独立积分复核 |
| 不确定性 | 局部协方差、参数bootstrap、模型情景 | 联合覆盖率、边界/失败分母、噪声敏感性 |
| 应用于给定场景 | 计算数据、英文论文、中文对照 | 正文图表同源、PDF实际渲染检查 |

## 为什么两次观测不够唯一确定真实运动

已知初始位置，再给两个时刻三维位置，一共只有六个独立新数据。速度、自旋、阻力、风、空气密度、相机误差不可能全自由估计。即使一条轨迹完全通过三个点，给它加上 c t(t-0.05)(t-0.10)，早期数据仍完全不变，未来却会改变；物理约束可以限制这种变化，不能凭空创造未观测的信息。

因此先采用有明确适用范围的六参数模型，再将无法识别的因素作为情景。不能把六参数恰好拟合六坐标称为实验验证，也不能从零残差估计测量精度。

## 系统、力与状态

球心为质点，坐标完全沿用题面，x指向球门。状态为r和v，输入为已知初始位置及两次带误差的球心坐标，输出为第一次向前穿过x=11时的(y,z,t)。不模拟守门员、球网和球杆碰撞；下降触地先于球门时明确报告，不继续假设弹跳。

控制方程：

\[
\dot{\mathbf r}=\mathbf v,\quad
\dot{\mathbf v}=-g\mathbf e_z-K C_D|\mathbf u|\mathbf u+\mathbf b\times\mathbf u,
\quad K=\frac{\rho\pi R^2}{2m},\quad\mathbf u=\mathbf v-\mathbf w.
\]

重力竖直向下；阻力与相对空气速度反向；有效Magnus力与相对空气速度垂直。b单位为s^-1，是自旋及其升力效率的合并参数，不是实际角速度。它可由常用近似CL正比于自旋比Rω/U导出，但该近似只是有限速度区间内的简化。基准固定w=0,bx=0，只估计初速三分量、CD、by、bz。固定bx是降维假设，不是证明它为零。

无风时，机械能满足 d[m|v|²/2+mgz]/dt=-mKCD|v|³≤0。Magnus项瞬时功率为零。空气有风时不能强求地面系机械能单调，因为空气可做功。

同样的轨迹主要识别KCD这个组合，改变质量/密度并允许CD重新拟合时，不应将全部变化误认作额外独立预测不确定性。球的型号及真实自旋、相机系统、时间误差均未知。

## 为什么噪声会被放大

令h=0.05 s。常加速度代数基线为v0=(4r1-r2-3r0)/(2h)，a=(r2-2r1+r0)/h²。这里r0精确、r1与r2各坐标误差独立同方差σ²，则a的标准差是sqrt(5)σ/h²：σ=1 cm时已有8.94 m/s²。

在固定t=8h=0.40 s外推，二次插值给r(t)=21r0-48r1+28r2，位置标准差sqrt(48²+28²)σ≈55.57σ。真实预测还需要解x(t)=11，因此到达时刻也不确定；不能只拿固定时间误差当球门误差。

## 反演与不确定性的含义

用带边界的非线性最小二乘最小化Σ||r模型(ti)-ri||²/σ²；等价于指定独立高斯误差下的最大似然估计。预测参数最优解对应的球门点，是模型条件下的点估计；没有物理先验和真实测量误差时，不宣称存在无条件的“最可能点”。

J为6个观测坐标对6参数的导数，G为入门(y,z)对参数的导数。内部解且局部满秩时，Cθ≈σ²(JᵀJ)^-1，Cgoal≈GCθGᵀ。95%联合椭圆用χ²(2)的95%分位数5.991；两个各95%的边际区间不等于95%的联合矩形。靠近边界时这个线性近似须谨慎。

参数bootstrap在拟合模型下重新产生带噪观测、逐次重新拟合，用于检查估计程序的重复采样变化。其越框频率不是现实进球概率，也不是贝叶斯后验概率；触地、失败、边界全部单独记账。

## 验证与适用边界

MATLAB负责主仿真、事件定位、抽样检验和正式图；Python使用独立DOP853积分和反演辅助复核。两种程序一致仅检验数值实现，不能证明空气动力学真实。解析重力与一维平方阻力作基准，分别检查时间步与事件求解上限；另用高精度积分生成独立合成轨迹，再检验预测和联合覆盖。

目前没有本场景的独立实测飞行轨迹，因此最终材料必须写“仅完成数值验证，未完成实验确认”。文献支持力的机制和量级，不能替代本题测量。低旋转尾流、突发阵风、相机系统误差、初始位置与时间误差、弹跳均是进一步扩展方向；不足以辨识时不得盲加自由参数。

## 实时环境与非唯一性实验

### 影响因素与本轮接入边界

| 因素 | 进入方程的位置 | 当前处理 |
|---|---|---|
| 踢球力度、触球方向 | 离脚初速度v0；冲量约为mΔv | 自由起脚模式调整初速倍率、水平/仰角；改变后重开球 |
| 常风、顺逆风、侧风、升降气流 | 相对速度u=v-w | 三分量风速可在播放中调整 |
| 阵风 | 随时间变化的w(t) | 可调横向/竖向峰值、开始时刻、持续时间 |
| 不稳定气流 | 时间相关扰动风 | 可调平滑扰动幅值；固定相位的确定性压力测试，不是校准随机湍流 |
| 阻力随速度变化 | CD=CD0·倍率·(U/30)^p | 可调阻力倍率和速度指数；经验形式不是特定球型已测曲线 |
| 旋转侧力、未知自旋轴 | b×u | 可调有效侧力倍率、bx及衰减时间；b不是实测角速度 |
| 空气密度 | ρπR²/(2m) | 可调代表环境值，改变气动加速度 |
| 球质量和半径 | m、迎风面积πR² | 自由起脚实验设置，重开球才生效 |
| 观测坐标、时间与相机偏差 | 逆问题的输入/测量协方差 | 本轮列为不确定性来源，未当成飞行中改变真实球轨迹的旋钮 |
| 接缝/球面朝向、低旋转尾流 | 非定常CD/侧力 | 以等效参数做压力测试；尚无本球型标定，不声称已实现可验证的真实尾流模型 |

固定观测模式的0–0.10秒沿已有基准积分，此后才施加环境变化，因而题给两次位置严格相同。自由起脚模式从t=0按新的初速积分，不再要求通过题给观测。固定观测模式锁定初速、方向与球属性，避免把事后改假设画成球在空中再次被踢或突然变重。

阵风采用紧支撑平滑脉冲：当a=(t-ts)/T位于(0,1)内时，w_g(t)=sin²(πa)(0,Ay,Az)，区间外为零。ts是起始时刻而非峰值时刻，T是总持续时间，峰值在ts+T/2。叠加常风和平滑时间扰动后，始终用u=v-w计算气动力。扰动相位不在每次ODE调用中随机抽样，保证相同参数可复现，步长加密不改变输入过程。

实时改参保存截至当前时刻的全部积分段，以当前r和v作为新段初值，只重算其后的解；编辑发生在0.10秒之前时，固定观测模式最早从0.10秒生效。连续拖动只更新未来，历史位置和速度不被重写。时间滑块可以回看过去，历史的风和力按当时那一段的参数显示；从过去再次改参将产生新的后续分支。

所有手动改参属于反事实场景或输入变化，不代表这些值已被六个观测坐标识别。特别是调整有效侧力倍率，表达的是气动假设切换，不应解释成真实足球在空中无力矩地瞬间反转自旋。空气浮力接口存在但默认关闭；未标定机制不通过强加精确参数获得虚假可信度。

有风时，Magnus力与相对空气速度垂直，但不一定与地面速度垂直。机械能的正确收支为dE/dt=(Fd+Fm+F浮)·v，不能在有外部气流时强求地面系机械能单调下降。无风基准保持原方程，原论文数值仍对应原假设；扩展情景暂供团队看效果和评估机制，不自动替换正式论文结果。

`scenario_checks`检验：零环境扩展回归旧解；阵风发生前位置和速度一致；从中途改风不改写历史且状态无跳变；两次编辑后回看历史仍使用旧风；阻力相对空气耗能非正、Magnus相对空气功为零；有风时的地面系功—能平衡；三档最大积分步长；提前触地分类；顺风/无风/逆风的到达时间次序；无效参数拒绝。结果写本版data/实时情景验证.json。

已跑通的示例：12 m/s横向阵风、开始0.15秒、持续0.20秒，使门线位置从约(11,2.5994,1.9670) m变为(11,2.7071,1.9732) m，偏移约0.108 m，前两次观测及阵风出现前的状态完全一致。这个数字只代表所选脉冲情景，不是未来落点的全局界或概率区间。飞行时间很短，合理量级的阵风不必然产生任意巨大的偏转。
